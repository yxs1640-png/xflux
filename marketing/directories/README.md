## Short description (~160 chars)

```
REST API for X/Twitter profiles, search, and timelines — plus scheduled account monitors with signed HTTP webhooks. 1,000 free calls/month, instant signup.
```

## Long description (~500 chars)

```
XFlux is a developer-focused platform for public X (Twitter) data. Use the REST API for on-demand reads — user profiles, timelines, tweet lookup, and search — with Bearer token auth and normalized JSON responses.

Add account monitors to watch @handles on a schedule without building your own poller. Paid plans deliver signed HTTP webhooks when new tweets are detected.

Free tier: 1,000 API calls/month and 1 monitor. Paid plans from $19/mo with webhooks and higher quotas. No official X API approval required. Self-serve docs and dashboard.
```
